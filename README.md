# ANR's Recipe Overlay (anr-ro)

Recipe overlay HUD for Minecraft 1.12.2 (Forge), driven by JEI, with optional
Just Enough Calculation integration. Keyboard-first: it sits on top of normal play
and never opens a screen or grabs the mouse.

Download: CurseForge, or the jar from [Releases](../../releases).

## Requirements
- Minecraft 1.12.2, Forge 14.23.5.2860+
- **Required:** [JEI](https://www.curseforge.com/minecraft/mc-mods/jei),
  [MixinBooter](https://www.curseforge.com/minecraft/mc-mods/mixin-booter)
- **Optional:** [Just Enough Calculation](https://www.curseforge.com/minecraft/mc-mods/just-enough-calculation),
  [Thaumcraft](https://www.curseforge.com/minecraft/mc-mods/thaumcraft) (essentia display)

## Reporting a bug
Open an [issue](../../issues/new/choose) with your Minecraft / Forge / anr-ro
versions, steps to reproduce, and your `logs/latest.log`.

## About this repository
This repository hosts the issue tracker and `update.json`, which Forge's update
checker reads to show "update available" in the Mods list. The mod's source is
not published here.
